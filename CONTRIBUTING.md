# Вклад в проект

Исправления опечаток, неработающих ссылок и ошибок в материалах приветствуются.

## Как предложить изменение

1. Создайте fork репозитория.
2. Создайте отдельную ветку.
3. Внесите небольшое, тематически целостное изменение.
4. Проверьте ссылки и отображение Markdown.
5. Создайте Pull Request с кратким описанием.

Не добавляйте в Pull Request решения закрытых домашних заданий, персональные данные студентов и материалы, на распространение которых у вас нет прав.
