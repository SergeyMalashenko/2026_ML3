# «Машинное обучение 3» — 2026

Материалы курса «Машинное обучение 3»: лекции, семинары и дополнительные
материалы по глубокому обучению.

Авторы курса:

- [Сергей Малашенко](https://github.com/SergeyMalashenko);
- [Александр Лощилов](https://github.com/aloschilov);
- [Арсений Зинкевич](https://github.com/arsen-z).

## О курсе

Курс посвящён основам глубокого обучения и современным нейросетевым
архитектурам. На занятиях рассматриваются принципы обучения нейронных сетей,
задачи компьютерного зрения и обработки естественного языка, трансформеры,
модели пространства состояний и методы эффективного дообучения моделей.

Основной формат практических материалов — Jupyter-ноутбуки с теорией,
примерами кода и заданиями для самостоятельной работы.

## Структура репозитория

Репозиторий подготовлен для последовательного наполнения материалами курса:

```text
.
├── assignments/  # задания
├── docs/         # программа и организационные документы
├── images/       # изображения для документации
├── lectures/     # материалы лекций
└── notebooks/    # семинарские ноутбуки
```

Материалы внутри каталогов будут группироваться по номерам занятий. Для
практических занятий могут публиковаться:

- основной ноутбук занятия;
- версия с заданиями для самостоятельной работы;
- версия с решениями;
- дополнительные конспекты, изображения и презентации.

## Как работать с материалами

Ноутбуки можно будет запускать в Google Colab или локально в JupyterLab.
Для локальной работы клонируйте репозиторий:

```bash
git clone https://github.com/SergeyMalashenko/2026_ML3.git
cd 2026_ML3
jupyter lab
```

Зависимости и требования к окружению будут указываться в материалах каждого
занятия.
