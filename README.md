# «Машинное обучение 3» — 2026

Материалы курса «Машинное обучение 3»: лекции, семинары и дополнительные
материалы по глубокому обучению.

Авторы курса:

- [Сергей Малашенко](https://github.com/SergeyMalashenko);
- [Александр Лощилов](https://github.com/aloschilov);
- [Арсений Зинкевич](https://github.com/arsen-z).

## О курсе

Курс посвящён основам глубокого обучения и современным нейросетевым
архитектурам. На занятиях рассматриваются принципы обучения нейронных сетей,
задачи компьютерного зрения и обработки естественного языка, трансформеры,
модели пространства состояний и методы эффективного дообучения моделей.

Основной формат практических материалов — Jupyter-ноутбуки с теорией,
примерами кода и заданиями для самостоятельной работы.

## Как работать с материалами

Ноутбуки можно запускать в Google Colab или локально в JupyterLab.
Для локальной работы клонируйте репозиторий:

```bash
git clone https://github.com/SergeyMalashenko/2026_ML3.git
cd 2026_ML3
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Для всех занятий используется одно окружение; общие зависимости перечислены
в корневом `requirements.txt`.

Для второго семинара локально также нужен системный Graphviz: проверьте
его наличие командой `dot -V`. Python-пакет `graphviz` не заменяет системную
установку. В Colab шапка notebook загружает модули курса и устанавливает
недостающие Python-пакеты для визуализации графов.

Во втором семинаре устройство выбирается в порядке MPS → CUDA → CPU.
Основной материал выполняется без заполнения пропусков; задания T1–T6
находятся в конце. При запуске всех ячеек незаполненный notebook остановится
на `NotImplementedError` в первом задании: это приглашение дописать решение.
