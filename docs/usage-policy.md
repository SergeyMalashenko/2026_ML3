# Правила использования материалов

Материалы репозитория создаются для обучения студентов и самостоятельного изучения компьютерного зрения.

## Разрешается

При соблюдении применимой лицензии разрешается:

- использовать материалы для личного обучения;
- делать локальные копии;
- использовать фрагменты в академической работе с указанием авторства;
- создавать личный форк для выполнения упражнений;
- предлагать исправления через Pull Request.

## Требуется отдельное разрешение

Без письменного разрешения правообладателя не допускается:

- использовать материалы в коммерческих курсах;
- перепродавать или перепубликовывать курс;
- включать материалы в платные образовательные платформы;
- распространять закрытые условия заданий и готовые решения;
- выдавать материалы курса за собственные;
- использовать материалы способом, прямо запрещенным файлом `LICENSE-MATERIALS`.

## Решения студентов

Не публикуйте решения домашних заданий в открытом доступе. Для личной работы используйте приватный репозиторий или локальную ветку, которая не отправляется в публичный удаленный репозиторий.
